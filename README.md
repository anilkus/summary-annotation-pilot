# Summary annotation pilot

Annotation tool for the pilot study on evaluating summaries of Turkish research papers (HPLT 4.0, TurkuNLP collaboration).

**Open the tool:** https://anilkus.github.io/summary-annotation-pilot/

- 40 texts (10 original abstracts and 30 model summaries) in random order, sources hidden
- The summary and the source paper are shown side by side, with a search box for the paper
- Rubric: grammatical correctness, self-contained, coherence, conciseness, coverage (yes/no questions, labels computed automatically)
- Progress is saved in your browser. Use **Export JSON** to save your annotations and send the file back.
